# Tripo-Multi-Agent-Travel-Planner






### For Set-up requirements for this project
1. set up venv in same folder.
2.python -m pip install -r requirements.txt
3. create .env
4.Create the tools folder in the way :
   1.__init__.py
   2.flight_tool.py
   3.travily_tools.py
5. now create the backend.py and app.py
6. create static folder.
